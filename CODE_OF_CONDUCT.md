# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the
work rather than the person. Harassment and discriminatory language are not tolerated in issues,
pull requests or any other project space.

## Reporting

If someone's behaviour concerns you, tell the maintainer,
[@bisratasfaw](https://github.com/bisratasfaw). For sensitive matters, open a short issue that
asks for a private contact channel (without details), or use GitHub's built-in
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
option, which goes to GitHub staff. The maintainer may remove comments or contributions that
break this code of conduct and may block repeat offenders, following the Contributor Covenant's
enforcement guidelines.
